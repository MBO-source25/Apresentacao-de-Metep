# Análise Interativa: Método Pré-Clínico In Vitro para Swabs Nasofaríngeos (SARS-CoV-2)

Site didático e interativo para estudo aprofundado do artigo *"A new in vitro pre-clinical method for testing SARS-CoV-2 nasopharyngeal swabs"* (Orjuela-Garzón et al., *Scientific Reports*, 2025).

## Recursos
- **Visualização Bilíngue:** Original em inglês e tradução técnica em português lado a lado ou individualmente.
- **Grifos Semânticos:** Filtragem por categoria (Problema/Objetivo, Metodologia, Resultados, Análise Crítica) e Modo Resumo.
- **Anotações Didáticas:** Notas vinculadas aos trechos do texto, estratégia PICO, tabelas de dados e análise crítica.

## Como publicar no GitHub Pages
1. Suba os arquivos `index.html`, `style.css`, `script.js` e `README.md` para um repositório público no GitHub.
2. Acesse **Settings** > **Pages**.
3. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Em cerca de 1 minuto o link do site estará ativo.
